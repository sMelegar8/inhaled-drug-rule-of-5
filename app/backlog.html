What to build or improve next

Work list that came out of building the first version. Each item says what to do, why it matters and roughly how much work it takes (S = a few hours, M = about a day, L = several days).

Data and integration

Covers 01_download_data.py and 02_build_database.py.

  • HighSplit combinations in FDA namesM Many of the 215 unlinked names are combinations in a single field ("A, B", "A || B", "A AND B"). This needs a many-to-many bridge table (product → components) and a new count of unlinked names.
  • HighManual spot check of the FDA → ChEMBL linkS Check 50 random rows per method and estimate the error rate. This is the number that makes the "inhaled" group credible.
  • HighSource attribution inside the appS ChEMBL is licensed under CC BY-SA 3.0 and must be credited; openFDA must be named as a source. The README and DATA_LICENSE.md already do this; the app pages should show it too.
  • MediumEuropean source for routes of administrationM openFDA covers the US market. EMA data on authorised medicines would add inhaled drugs approved in Europe, closer to the context of European companies.
  • MediumMore respiratory targetsS Beyond PDE4: the β2-adrenergic receptor, the muscarinic M3 receptor and the glucocorticoid receptor. This allows comparing different inhaled therapeutic classes.
  • MediumOne command for the whole pipeline, and pipeline testsM A run_pipeline.py script and pytest tests on strip_salts, on name linking and on the expected table counts. Today CI checks only the app statistics.
  • HighCharge and ionisation of the moleculesM The ChEMBL 37 API does not return logD, pKa or molecular species (the columns are always empty). For inhaled drugs charge matters: many anticholinergics are quaternary ammonium compounds. Calculate formal charge and ionisable groups with RDKit.
  • MediumRDKit for descriptors and scaffoldsM RDKit is already used for the structural motifs. Next: validate the SMILES, recalculate the descriptors that today come from ChEMBL, and group compounds by scaffold (Bemis-Murcko).
  • LowIncremental download with hash comparisonS Download again only if the ChEMBL release or the openFDA export changes, and report the differences from the previous build.
  • LowFull ChEMBL dumpM Needs about 30 GB of free space. It would give direct access to products, formulations and all activities, without API limits.

Cleaning and statistical analysis

The next phase of the project, in Python with pandas.

  • HighManual review of inhaled drugs without an ATC codeS 7 molecules in the inhaled group have no ATC code and escape rules M3-M6. Pentetic acid (DTPA) acts systemically and should probably be excluded: this needs a documented rule, not a manual deletion.
  • HighStatistical comparison of inhaled vs oral drugsM Mann-Whitney test for each property, effect sizes, bootstrap confidence intervals and correction for multiple comparisons. With 46 inhaled drugs the effect size matters more than the p-value.
  • HighExplainable inhalability scoreM A few rules or a simple logistic regression. Required check: budesonide, formoterol and tiotropium must get a high score.
  • MediumApplication to PDE4 compoundsM Calculate the score for potent PDE4 inhibitors (pIC50 ≥ 7) and show which chemotypes are best suited to inhalation.

In-browser SQL app

Covers app/index.html.

  • HighSyntax highlighting and autocompletionM A real editor (CodeMirror) with SQL colouring and suggestions of tables and columns read from the schema.
  • HighWebAssembly SQL engineS The app uses the asm.js build of sql.js. The WebAssembly build is faster but needs the .wasm file published next to the page.
  • MediumQueries in a Web WorkerM A long query currently blocks the page. In a worker the interface stays responsive and a "Stop" button can be added.
  • MediumHistory and saved queriesS Find recent queries again and name the ones that are useful for the analysis.
  • MediumRegression and more chartsM Trend line with R² on scatter plots, scatter matrix, 2D density. Descriptive statistics, correlations, PCA and group tests are already in the statistics panel.
  • MediumClustering (k-means) on PCA scoresM Group molecules by chemical profile and see whether inhaled drugs form a cluster of their own. To be validated against scikit-learn, like the PCA.
  • LowBootstrap confidence intervals in the appS For medians and effect sizes of small groups (46 inhaled drugs). Today they are planned for notebook 03.
  • MediumChemical structure in the tooltipM Draw the molecule from its SMILES when hovering over a point. For a pharma audience this makes the charts readable at once.
  • MediumResults of several statements in tabsS With several queries separated by semicolons, only the last result is shown today.
  • LowChart exportS Enable PNG/SVG download for slides; the button is currently removed from the chart toolbar.
  • LowPagination and filters in the results tableS The table shows the first 1,000 rows; the chart always uses all rows.
  • LowForeign keys and a diagram in the schema panelS Show which columns link the tables, so JOINs can be written without opening the documentation.
